# 강의와 배포본 연결

강사의 Notion 「AI 트레이딩 Agent」, 「TradingCodex 멀티 에이전트 투자 팀」,
18·19·21강을 대조하고 원본 저장소의 운영 규칙을 기준으로 구성했습니다.
강의 전문·스크린샷·비공개 수강 자료는 이 배포본에 복제하지 않았습니다.

| 학습 주제 | 배포본에서 사용하는 곳 |
| --- | --- |
| Agent·프롬프트·하네스·Skill | AGENTS, 네이티브 역할 TOML, hyperpass-team 스킬 |
| 데이터 소스·MCP | 이미 활성화된 읽기 도구 또는 공개 자료·제공 파일; 필수 MCP 없음 |
| 기술·기본·시장 분석 | 해당 전문 역할과 원본에서 이식한 방법 |
| 위험·포트폴리오 관리 | 독립 역할 및 사용자 제공 포트폴리오 기반 분석 |
| 백테스트·해석 | 계산 재현과 anti-overfit 검토; 백테스트 엔진은 별도 |
| 멀티 에이전트 | Head Manager의 동적 최소 팀·병렬 분석·인계·독립 검토 |
| 자동매매 아키텍처·주문 실행 | 연구 결과의 후속 인계 개념; 실제 주문 계층은 포함하지 않음 |
| 최종 통합·복기 | 버전별 보고서, 판단 스냅샷, 사후 평가·교훈 제안 |

19강의 단계별 학습 예시(분석·Bull/Bear·리포트 역할)를 별도 필수 팀으로 합치지
않았습니다. 수강생용 운영팀은 사용자가 기준으로 지정한 Git의 9개 전문 역할을
유지합니다. 전체 강의의 모든 실습 기능이 이 연구 배포본에 구현됐다는 의미는 아닙니다.
