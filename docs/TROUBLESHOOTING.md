# 막혔을 때

| 증상 | 확인·조치 |
| --- | --- |
| 역할이 보이지 않음 | `AGENTS.md`가 있는 폴더를 열었는지 확인하고 해당 프로젝트의 새 채팅에서 확인 |
| 역할 파일은 있는데 실제 호출 불가 | 파일 존재와 런타임 등록은 다름. 앱의 실제 오류와 버전을 기록; 가짜 역할극 금지 |
| 일반 분석가는 가능하지만 독립 검토 역할 불가 | 해당 결론을 검토 완료로 표시하지 않고 blocked/waiting으로 남김 |
| TradingCodex 인증·MCP 오류가 나타남 | 원본 프로젝트나 기존 전역 MCP에서 난 것인지 확인. 이 패키지는 해당 서버를 요구하지 않음. 기존 설정을 자동 삭제하지 않음 |
| 자료 조회 도구 인증 실패 | 유효한 기존 결과를 보존하고 공개 자료·제공 파일로 대체 가능한 범위만 진행. 현재 시세 등 미확인 항목 명시 |
| 계산 실행 도구가 없음 | 숫자 결론을 계산한 것처럼 쓰지 않음. 입력·공식·미실행 항목을 남김 |
| 쓰기 권한 오류 | 앱의 정상 프로젝트 권한 흐름을 확인. 보고서 저장 전에는 기록 기능 성공을 표시하지 않음 |
| Windows 긴 경로/동기화 잠금 | OneDrive·공유 드라이브 밖의 짧은 새 사용자 폴더에 ZIP을 풀고 다시 프로젝트로 열기. 기존 작업 삭제 금지 |
| Mac에서 숨김 폴더가 안 보임 | ZIP 안의 `.codex`와 `.agents`를 포함해 폴더 전체를 유지. Finder 표시는 `Command+Shift+.` |
| Codex CLI sandbox setup 실패 | 앱과 별도 CLI의 관리 주체가 다를 수 있음. 앱 프로젝트 흐름으로 확인. 관리자 실행 반복·계정 삭제·ACL 완화 금지 |
| `app runtime provisioning service is unavailable` | 앱 번들 CLI를 별도로 실행할 때 확인된 호스트 문제. Codex 앱에서 프로젝트를 열어 확인하며, 샌드박스 해제나 별도 관리자 설정을 해결책으로 쓰지 않음 |

오류를 전달할 때는 앱 버전, OS, 실패 단계, 민감정보를 지운 오류 문구를 함께
제공하세요. 토큰·비밀번호·계좌번호·전체 환경변수·인증 파일은 보내지 마세요.
같은 설치나 호출을 반복하지 말고 원인이 바뀐 뒤 필요한 단계만 재검사합니다.

이 패키지는 기존 글로벌 MCP·Hooks를 지우거나 비활성화하지 않습니다.
전역 설정 때문에 생긴 문제를 자동으로 해결했다고 주장하지 않습니다.
