# Codex에 준비를 맡기는 프롬프트

먼저 강사가 제공한 배포 ZIP을 풀어 Codex에서 폴더를 여세요. 이 프롬프트는
서버를 설치하는 대신 이미 받은 프로젝트를 준비합니다. API 키를 요구하지 않습니다.

```text
나는 초보 수강생이야. 받은 Hyperpass Agent Team 폴더를 Codex 앱에서 사용하고 싶어.
현재 프로젝트에 README.md, AGENTS.md, START-HERE.md, .codex/agents와
.agents/skills/hyperpass-team이 있는지 확인해줘.
다른 폴더를 열었다면 원래 파일을 수정하거나 재설치하지 말고 올바른 폴더를 안내해줘.
기존 TradingCodex나 다른 프로젝트에 병합하지 마.

필요한 사용자 조작은 한 번에 하나씩 쉬운 말로 설명해줘.
설정 파일 존재와 실제 기능 작동을 구분하고, 새 채팅에서 역할이 로드되어야 한다면
재개 문장을 남겨줘. 전역 설정, 샌드박스, Hooks, MCP, 로그인 정보를 변경하지 마.
Python·Django·uv·브로커 MCP를 설치하지 마. 인증정보를 채팅에 요구하지 마.

준비가 되면 START-HERE.md의 가상 자료 점검을 실제로 실행해줘.
실제 두 역할의 호출·검수·독립 검토·최종 보고서 저장까지 확인한 경우만
기본 팀 점검 완료라고 알려줘. 부족한 기능은 꾸며내지 말고 구체적으로 알려줘.
계좌 조회, 주문, 예약, 외부 메시지는 하지 마.
```
